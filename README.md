A loading-screen tip written for a tired developer and the AI coding agent working beside them, all in one line under 200 characters.
It sets up a scene, turns once, and leaves the last word to whoever is still at the keyboard at 98%.

```sh
python3 main.py && cat "${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt"
```

The program is Python 3 standard library only, makes no network calls, and writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed.
